Four-Way Traffic Signal Simulator (C + SDL2)
Open FourWayTraffic.cbp in Code::Blocks. Configure SDL2 include/lib paths if needed and place SDL2.dll beside the executable.
Direction names and RED/YELLOW/GREEN controls use larger text for readability. Removed keyboard-hint and LIVE TRAFFIC headings from the corner panels.
Vehicle types include cars, buses, trucks, auto-rickshaws, motorcycles and scooters.
